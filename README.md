# chunleige.github.io

Personal website of Chunlei (Ivyann) Ge, built with [Quarto](https://quarto.org).

## How to edit (no installation needed)

1. Open the file you want to change on GitHub and click the ✏️ pencil icon.
2. Edit the text. It is plain Markdown.
3. Click **Commit changes**.
4. Wait about 2 minutes. The site rebuilds itself (see the **Actions** tab) and the change goes live.

## Which file is which

| To change…                         | Edit this file                         |
|------------------------------------|----------------------------------------|
| Home page text, news, skills       | `index.qmd`                            |
| Research summary                   | `research.qmd`                         |
| Publications                       | `publications.qmd`                     |
| Talks                              | `talks.qmd`                            |
| CV                                 | `cv.qmd`                               |
| Add a portfolio project            | copy a file in `portfolio/` and edit it |
| Menu items, site title             | `_quarto.yml`                          |
| Colours and fonts                  | `theme.scss`                           |

Images go in `images/`, PDFs (CV, slides) in `files/`.

## Optional: preview on your own computer

Install Quarto, then run `quarto preview` in this folder.
